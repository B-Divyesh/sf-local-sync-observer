Privacy, in plain terms.

The short version

Local Sync Observer has no account, analytics, advertising, or telemetry. Its desktop app communicates only with local endpoints and folders that you choose. We do not receive that information.

Data on your device

The app stores source labels, folder paths, local endpoint URLs, API keys, and cached status readings in its local WebView storage. API keys are stored locally but are not currently encrypted by the app. Remove a source to delete its settings and reading; uninstalling follows your operating system’s application-data removal behavior.

What the observer reads

For Syncthing, it reads folder configuration and status counts from the local REST API. For folders, it reads names, timestamps, file types, and sizes to identify common conflict-copy patterns. It never opens or transmits file contents.

This website

The website uses no cookies or analytics. Static hosting and GitHub release downloads may process ordinary server logs under their operators’ policies.

Contact

Questions can be filed in the project’s public issue tracker.
