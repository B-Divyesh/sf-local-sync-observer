Privacy, in plain terms.

The short version

Local Sync Observer has no product account, analytics, advertising, or telemetry. Its desktop app contacts only local addresses and folders you choose.

We do not receive that information.

Data on your device

The app stores source labels, folder paths, local addresses, API keys, and cached readings in local WebView storage.

Version 0.1 does not encrypt API keys. Remove a source to delete its settings and reading.

What the observer reads

For Syncthing, it reads the folder list and status counts from the local API.

For Nextcloud, it reads the desktop client log for status messages. It never changes the log or synced files.

For folders, it reads names, timestamps, file types, and sizes to find common conflict-copy patterns. It never opens or transmits file contents.

This website

The website uses no cookies or analytics. It removes a cached GitHub release response after one hour.

The demo uses a separate local-storage key and never reads real app data.
