SYNC STATUS CHECK

Why one sync reading helps

After reconnecting, “idle” may not mean every device agrees. The observer combines Syncthing status, Nextcloud desktop logs, and conflict-copy names.

How it works

How the observer checks a source

  1. 01

    Add a local source

    Add Syncthing, a Nextcloud desktop log, or a folder. Credentials and paths stay in the app’s local storage.

  2. 02

    Check the status and its limits

    See pending activity, conflicts, the last completed sync, and any details your sync tool did not report.

  3. 03

    Open the sync tool

    Open the affected sync tool from its row. The observer uses read-only checks and does not change your files.

Status limits

When the reading is unknown

If a check cannot show that syncing finished, the board says so. Every status lists its checks and any missing Syncthing details.

↳ A folder check can find common conflict copies. Only Syncthing’s pending count can establish “Converged.”

Current coverage

Provider coverage and limits

ST

Syncthing

Reads Syncthing’s local folder list and pending-file count. It also checks folder names for conflict copies.

Can show when syncing finished
NC

Nextcloud desktop

Reads its local log for conflicts, connection problems, pending activity, and completed syncs.

Shows status; no exact pending count
FS

Any local folder

Reads names, sizes, and timestamps only, capped at 50,000 entries and 16 levels. Never opens file content.

Conflict hints; sync completion unknown
