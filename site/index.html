THE OLD ROUTINE

Four tabs. Three logs. Still no answer.

After reconnecting, “idle” does not always mean every device agrees. Local Sync Observer turns each provider’s evidence into a careful reading—and refuses to call folder metadata alone “synced.”

The two-minute check

Observe. Explain. Hand off.

  1. 01

    Connect local evidence

    Add a loopback Syncthing API or choose a folder. Credentials and paths stay in the app’s local storage.

  2. 02

    Read the boundary

    See pending counts, known conflict-copy names, last-good checks, and exactly what the provider did not report.

  3. 03

    Fix it at the source

    Open the owning tool from the affected row. The observer never resolves, renames, or deletes anything.

Designed for honesty

“Unknown” is a feature.

If an integration cannot prove convergence, the board says so. Every status includes its evidence coverage, so a reassuring color never outruns the facts.

↳ Folder observation can detect common conflict copies. Only provider-reported pending counts can establish “Converged.”

Coverage in v0.1

Small surface. Explicit limits.

ST

Syncthing

Reads local REST folder configuration and needFiles; scans configured folder names for common conflict copies.

Convergence evidence supported
FS

Any local folder

Reads names, sizes, and timestamps only, capped at 50,000 entries and 16 levels. Never opens file content.

Conflict hints; convergence unknown
+

More providers

Nextcloud and Resilio adapters are not in v0.1. Their folders can be observed, but provider-specific pending state is not claimed.
